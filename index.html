What I've been rebuilding

Big Bang Racing 2.4.9 Server

2026 · ONGOING

The original C# server source for this mobile racer had been permanently deleted. Working from an already-decompiled copy of the production binary, I rebuilt it from scratch and verified it byte-for-byte against the original. From there I kept extending it : tournaments, a versus mode, and a custom UDP broadcast protocol so the app finds the server on any network without touching a phone's DNS. I also patched the Android client's compiled bytecode directly (IL rewriting) to restore development tooling the shipped build had stripped out.

What On Earth Offline

2026 · OFFLINE PATCH + 3 PLATFORMS

What On Earth is the very first version of Big Bang Racing, long pulled from the app stores. I built the server it talks to from scratch, then put together a fully offline build that needs no server at all, playable on Android, iOS and PC. The iOS leg was its own fight : cross-compiling a 2018 Unity project and chasing a crash that only showed up on 64-bit devices, where the physics engine's assumption that a point was always double-precision broke under arm64's calling convention. Fixed that, then solved a separate code-signing wall by splitting the universal binary into two architecture-specific IPAs.

BBRo (Big Bang Racing Offline) — iOS

2026 · iOS PORT

BBRo is a community-made offline mod of BBR, originally built for Android and Windows only. I ported it to iOS : compiled it through Xcode, patched the same native physics plugin that needed fixing on the other iOS port, and shipped it as signed 32-bit and 64-bit IPAs ready to sideload.
